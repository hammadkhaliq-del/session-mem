# sessionmem — surprise site

A handcrafted static showcase built only with HTML, CSS and JavaScript.

## Run
Open `index.html` or serve locally with:
`python -m http.server 8000`

## Design
The site intentionally avoids the original bento-grid structure. It uses an editorial/devtool visual system: terminal memory machine, query studio, architecture map, evaluation console, security manifesto and build log.
